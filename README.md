# Painel de Clientes — versão pronta para GitHub Pages

Esta versão está organizada para publicação direta no GitHub Pages.

- `index.html` fica na raiz do projeto.
- `style.css` e `script.js` ficam na raiz.
- Os dados são carregados da API pública JSONPlaceholder.
- A busca filtra os clientes pelo nome.
- O gráfico mostra a distribuição por cidade.

## Publicação

No repositório que será usado pelo GitHub Pages, envie os arquivos da raiz deste ZIP (`index.html`, `style.css`, `script.js` e `README.md`). Não renomeie o ZIP para `index.html`.
